# 포트폴리오 소개

## 이 사이트가 하는 일

컷앤킵 포트폴리오는 사진, GIF, 짧은 영상을 한 문장으로 다루는 서비스 컷앤킵을 읽는 설명 사이트다.
기능을 다시 구현하지 않는다. 이미 저장소와 운영 서버에 있는 구성을, 역할별로 짧게 보여 준다.

읽는 순서는 아래와 같다.

1. 이 소개에서 제품이 무엇인지 본다.
2. 사용자 앱, 운영 콘솔, 백엔드, AI 서비스 중 필요한 장으로 들어간다.
3. 데이터 구조가 필요하면 ERD와 스프레드시트를 본다.
4. 문장으로 더 묻고 싶으면 안내 챗을 연다. 기록은 이 브라우저에만 남는다.

## 프로젝트

컷앤킵(Cut & Keep)은 자연어 한 줄로 원하는 대상만 남기거나, 필요 없는 대상을 지우는 웹 서비스다.

예시 문장:

- "강아지만 남기고 배경 제거"
- "맨 앞 빨간 안전모 쓴 사람만 남기고"
- "오른쪽 사람 지워줘"

입력은 사진 한 장, 움직이는 GIF, 최대 20초의 짧은 영상, 회원의 배치(최대 500장)다.
출력은 투명 PNG, JPEG, 투명 GIF와 WebP, H.264 mp4다.

개발은 2026-07-27 첫 커밋부터다. 2026-10-11에 Oracle Cloud 실서버 배포를 마쳤고, 2026-10-12 인수인계 기준으로 공개 운영 중이다.

| 구성 | 기술 | 주소 |
|------|------|------|
| 사용자 앱 | React, TypeScript, Vite 7 | 로컬 5173, 서버 nginx 80, Cloudflare Worker |
| 운영 콘솔 | React, TypeScript, Vite 7 | 로컬 5174. 서버 Compose에는 없다 |
| 백엔드 | FastAPI | 8000. 공개는 Caddy 443 뒤 |
| 데이터 | MariaDB 11, 호스트 개발은 SQLite | 서비스 기록과 학습 기록을 나눔 |
| 문장 해석 | Ollama. 기본 `gemma4:e4b` | 운영은 PC의 Ollama를 SSH 터널로 연결 |
| 대상 찾기 | YOLO26m-seg, SegFormer | 오픈 보캐브는 코드만 있고 기본은 꺼짐 |

공개 주소는 `https://168-110-17-193.sslip.io` 다.
화면은 Cloudflare Worker `cutnkeep-front`가 정적 파일을 주고 `/api`와 `/health`를 서버로 넘긴다.
자체 도메인은 아직 없다.

## 한 줄로 보는 기능

| 기능 | 누가 | 결과 |
|------|------|------|
| 배경 제거 | 모두 | 대상만 투명 PNG 또는 GIF |
| 배경 블러, 크롭 | 모두 | 대상은 선명하고 나머지는 흐리거나 잘림 |
| 대상 지우기 | 모두 | 사진은 LaMa, 영상과 GIF는 다른 프레임의 배경 |
| 대상 고르기 | 모두 | 위치, 순서, 개수, 크기, 색 |
| 작업 기록, 평가, 배치 | 회원 | 본인 것만. 파일은 24시간 |
| 검수, 회원, 시스템 | 관리자 | 운영 콘솔 |

비로그인 사용자는 처리하고 바로 내려받기만 한다. 서버에 원본과 결과를 남기지 않는다.

## 처리 한 줄

문장 해석, 전처리, 세그멘테이션, 검증과 재시도, 효과, 필요하면 피드백 수집.
이 순서는 LangGraph 파이프라인이다. 해석이 불확실하면 조건을 바꿔 한 번 더 찾고, 더 나은 마스크를 고른다.

## 숫자로 확인된 것

수치는 실험 기록이다. 모든 문장과 모든 영상에 대한 보장은 아니다.

| 항목 | 기록 |
|------|------|
| 처음 보는 문장 해석 체인 | 86.7%에서 96.7% |
| LoRA, 조합형 283문장 | 94.7%, GPU에서 문장당 약 1초 |
| Ollama 체인 비교 | 약 85%대. 기본 운영은 여전히 Ollama e4b |
| "왼쪽 사람" 선택 | 90.0% |
| 실제 영상 추적 DAVIS | 맞은 비율 72.8%에서 92.1% |
| 테스트 (2026-10-12) | 백엔드 505, 프론트 95, 콘솔 21 |

## 지금 한계

- 서버의 문장 해석은 운영자 PC의 Ollama 터널이 켜져 있어야 한다. 꺼지면 키워드 파서로 내려가고 서비스는 계속된다.
- Cloudflare Worker는 약 100초에서 끊긴다. 27b, 모델을 막 바꾼 12b, 긴 영상과 GIF는 서버 주소가 더 여유가 있다.
- 운영 콘솔은 공개 서버에 올리지 않았다. 관리자 PC에서 서버 API로 붙인다.
- 오픈 보캐브(Grounding DINO와 SAM2)는 가중치가 없고 기본은 꺼져 있다.
- 백업은 같은 서버 디스크의 최근 7일이다.
- 운영자 실명과 자체 도메인은 아직이다.
