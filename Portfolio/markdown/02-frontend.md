# 사용자 앱 (프론트엔드)

## 개요

사용자 앱은 저장소 `frontend/`에 있다. React 18, TypeScript 5, Vite 7, Tailwind CSS 3, Zustand 4다.
라우터는 라이브러리가 아니라 `src/router.tsx`의 History API다. 테스트는 Vitest 5다.

로컬 개발 주소는 `http://localhost:5173`이다. `/api`와 `/health`는 Vite가 `localhost:8000`으로 넘긴다.
Docker에서는 nginx가 80번에서 정적 파일을 주고 같은 경로를 백엔드로 프록시한다.
공개 화면의 다른 경로는 Cloudflare Worker다. Worker가 정적 파일을 주고 API만 원본 서버로 보낸다.

비로그인과 회원의 차이가 화면의 기준이다.
비로그인은 사진, GIF, 영상을 처리하고 그 자리에서 내려받는다.
회원은 작업 기록, 작업 상세, 평가, 정답 알려주기, 배치, 내 계정을 쓴다.

## 엔진

| 역할 | 선택 |
|------|------|
| 화면 | React 함수 컴포넌트 |
| 언어 | TypeScript |
| 빌드 | Vite 7 |
| 모양 | Tailwind와 `src/index.css`의 `card`, `field`, `eyebrow`, `step-dot` |
| 상태 | Zustand. 작업, 로그인, 고른 해석 모델 |
| 글꼴 | Pretendard. 빌드에 포함하고 외부 CDN은 쓰지 않음 |
| 라우팅 | `navigate`, `matchRoute` |

서버 상태는 머리글의 점을 30초마다 `GET /health`로 갱신한다. 초록이면 연결되어 있다.

## 화면

| 경로 | 하는 일 |
|------|---------|
| `/` | 비교 데모, 예시 문장, 사용 순서, 최근 작업 |
| `/studio` | 사진. 1 올리기, 2 문장, 3 처리 |
| `/studio?type=gif` | GIF. 프레임 간격과 반복 유지, 최대 120프레임 |
| `/video` | 최대 20초, 80MB, 긴 변 3840. 결과는 mp4 |
| `/batch` | 회원. 같은 문장으로 최대 500장, 진행률, zip |
| `/account` | 회원. 내 정보, 기록, 보안, 탈퇴 |
| `/account?tab=history` | 사진, 영상, GIF 기록. `/history`는 여기로 이동 |
| `/jobs/:id` | 결과 다시 보기, 해석 JSON, 같은 문장으로 다시 작업 |
| `/guide` | 문장 쓰는 법 |
| `/guide?tab=agent` | AI 채팅. 추천 문장을 작업실에 채움 |
| `/login`, `/signup`, `/signup/verify` | 로그인, 이메일 일련번호 가입 |
| `/find-id`, `/find-password` | 아이디와 비밀번호 찾기 |
| `/privacy`, `/terms` | 개인정보 처리방침, 이용약관 |

가입은 두 단계다. 정보를 넣고 동의한 뒤, 메일로 온 8글자 일련번호를 `/signup/verify`에 넣으면 계정이 생긴다.
동의는 만 14세 이상, 이용약관, 개인정보 처리방침이다. 서버도 검사하고 동의 시각을 남긴다.
일련번호는 30분, 5회, 다시 받기는 60초 간격이다.

작업실의 해석 모델 상자는 Ollama e4b, 12b, Qwen 3.8 27b를 고른다.
서버에 없는 모델은 "미적용"이고 고를 수 없다. 고른 값은 이 브라우저에 남는다.
GPU 서버가 LoRA로 해석하면 이 상자는 숨는다. 배치는 서버 기본 모델만 쓴다.

영상 마지막 결과 한 개는 브라우저 IndexedDB에 남는다. 비로그인 결과의 서버 사본은 없으므로, 그 브라우저 저장이 유일한 사본이 된다.

## API 연결

프런트는 백엔드 `/api/v1`만 호출한다. 데이터베이스에 직접 붙지 않는다.

| 화면 동작 | 호출 |
|-----------|------|
| 서버 상태 | `GET /health` |
| 사진 처리 | `POST /api/v1/upload` (`file`, `prompt`, `llm_model`) |
| GIF | `POST /api/v1/gif` (`matte`는 none, light, dark) |
| 영상 | `POST /api/v1/video`, `GET /api/v1/video/{id}` |
| 내 기록 | `GET /api/v1/jobs` |
| 결과 파일 | `GET /api/v1/files/{id}/before|after|thumb|webp` |
| 평가 | `POST /api/v1/feedback` |
| 배치 | `POST/GET /api/v1/batch`, 항목, zip |
| 계정 | `/api/v1/auth/*` |
| 모델 목록 | `GET /api/v1/llm/models` |
| 안내 채팅 | `POST /api/v1/chat` |

로그인 세션은 HttpOnly 쿠키다. 스크립트가 토큰을 읽지 않는다.
비로그인 처리 응답은 파일을 저장하지 않고, 화면이 바로 내려받게 한다.

채팅은 서버에 대화를 쌓지 않는다. 화면이 최근 대화를 요청마다 보내고, 서버는 답만 돌려준다. 새로고침하면 사라진다.
이 포트폴리오 사이트의 안내 챗과는 별개다. 제품 챗은 요청 문장을 만들어 주는 기능이고, 포트폴리오 챗은 이 프로젝트를 설명해 주는 기능이다.

## 내부 화면과 스크린샷

디자인 확인 캡처는 `docs/vaildates/ui-design-20261008-*.jpg`다.
홈은 비교 슬라이더, 작업실은 단계와 실제 처리 결과, 좁은 화면은 이름이 보이는 펼침 메뉴다.
실행 중 화면 기록은 `logs/ui_check/`에 있고, 그 폴더는 Git에 올라가지 않는다. 포트폴리오 사이트는 확인용으로 고른 장면만 다시 담는다.

캡처가 보여 주는 것:

- 홈. 배경 제거, 대상 지우기, 배경 블러 탭과 손잡이
- 작업실. 사진, 문장, 처리, 해석 칩, 원본과 결과
- 모바일 메뉴. 1024px 미만
- 회원 기록과 작업 상세
- 영상 결과, 배치 완료

홈 데모 그림은 실제 인물 사진이 아니다. 저작권과 초상권 때문에 SVG로 그렸다.

## 디자인

다크 테마를 유지하고 완성도를 올렸다. 밝은 테마 전환은 하지 않았다.
한국어는 `word-break: keep-all`로 낱말 중간에서 끊기지 않게 했다.
키보드 초점 링을 맞추고, 움직임 줄이기 설정을 따른다.
1024px 미만은 아이콘만이 아니라 메뉴 이름이 보이게 펼친다. 페이지를 옮기면 메뉴는 닫힌다.

2026-10-08 확인에서는 데스크톱 1440과 모바일 390에서 가로 스크롤이 없었다.
그 시점의 프론트 테스트는 44개였다. 이후 계정, 영상, GIF, 채팅이 늘어 인수인계의 프론트 테스트는 95개다.

## 문제와 개선

이미 반영한 것:

- 한글이 글자 중간에서 끊기던 줄바꿈
- 모바일에서 아이콘만 보이던 메뉴
- 작업실을 단계와 진행 막대로 재구성
- 비로그인 저장 없음, 회원 기록, 이메일 인증 가입
- 영상과 배치 화면. 예전에는 API만 있었다

아직인 것:

- Cloudflare 경유 시 긴 영상, GIF, 큰 해석 모델이 약 100초에서 끊긴다. 화면은 안내만 한다. 서버 직접 주소는 약 300초다.
- 실제 휴대폰과 실제 메일함의 가입 버튼은 인수인계에 미검증으로 남아 있다.
- 접근성 자동 점검 도구는 돌리지 않았다.
- AI 채팅 스트리밍은 없다. 답을 한 번에 받는다.
- 이메일 주소 변경과 기존 회원의 이메일 재인증은 없다.

예정:

- 마스크를 COCO 또는 YOLO-seg 형식으로 내려받기
- 브라우저 안에서 ONNX로 처리해 서버에 사진을 보내지 않는 경로
- 채팅 응답을 나누어 받기

## 이후 방향

사용자 앱은 지금 흐름을 유지한다. 올리기, 문장, 결과, 회원만 기록.
공개 주소가 자체 도메인이 되면 Worker의 원본 주소와 화면의 운영자 표기를 같이 바꾼다.
긴 작업은 Worker 제한을 넘는 경우를 화면에서 더 분명히 안내하는 쪽이 먼저다.
콘솔과 같은 세션 쿠키를 쓰므로, 로컬에서 콘솔에 관리자로 로그인하면 같은 브라우저의 사용자 앱도 그 계정이 된다. 다른 계정 시험은 시크릿 창이 맞다.
