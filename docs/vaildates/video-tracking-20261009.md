# 영상 · GIF 고른 대상 따라가기 (2026-10-09)

> 실행: `python scripts/experiments/video_tracking_eval.py --n 40 --seg oracle` · `--n 20 --reps 2 --seg yolo`
> 원자료: [`video_tracking_eval_oracle_20261009.json`](./video_tracking_eval_oracle_20261009.json) · [`video_tracking_eval_yolo_20261009.json`](./video_tracking_eval_yolo_20261009.json)
> 코드: `backend/app/services/instance_tracker.py` · `video_processor.FrameRenderer` · 설정 `VIDEO_TRACK_INSTANCES` (기본 true)

## 문제

영상 · GIF 는 프레임마다 세그를 돌리고, "왼쪽 사람" · "맨 앞 사람" 같은 selector 도 **프레임마다 다시** 적용했다.
두 사람이 서로 지나가면 지나간 뒤에는 "왼쪽"이 다른 사람이 된다. 그래서 배경 제거 · 블러 · 지우기 효과가 중간에 다른 사람으로 옮겨 갔다.

## 바꾼 것

- 위치 · 순서 · 개수가 있는 selector 는 **첫 프레임에서 한 번만** 고르고, 이후 프레임에서는 그 인스턴스를 따라간다
  - 같은 대상인지는 직전 모습을 속도만큼 옮긴 예측 위치와의 IoU(가중치 0.6), 그리고 마스크 안 색 분포(H·S 히스토그램) 유사도(가중치 0.4)로 판단한다
  - 색 유사도가 0.35 미만이면 위치가 겹쳐도 다른 대상으로 본다
- **고르지 않은 사람도 같이 추적한다.** 앞을 지나가는 다른 사람은 그 사람의 추적이 먼저 가져간다. 그래서 고른 대상이 가려지는 동안 효과가 그 사람으로 옮겨 가지 않는다
- 일부만 보이면(면적이 평소의 70% 미만) 보이는 조각의 무게중심을 믿지 않는다. 대신 예측 위치를 이어 간다. 그렇지 않으면 가려지는 동안 속도가 0으로 무너진다
- 놓치면 예측 위치 근처(3px 확장)에서 색이 비슷한 남은 인스턴스와 한 번 더 짝짓는다. 가려졌다가 조각으로 다시 나타나는 경우를 위한 것이다
  - 8프레임 넘게 못 찾으면 selector 로 다시 고른다. 그동안 효과는 직전 마스크를 유지한다(기존 동작) → 이후 색으로 다시 찾기 · 24프레임으로 보완 ([`video-tracking-hard-20261009.md`](./video-tracking-hard-20261009.md))
- 개수가 정해지지 않은 조건(예: "빨간 옷 입은 사람들")은 새로 들어온 사람도 포함해야 하므로 지금처럼 프레임마다 고른다

## 평가

**합성 영상(정답 있음):** 사람이 없는 COCO 사진을 배경으로 쓴다. 다른 사진의 사람 두 명을 잘라 붙여 서로 반대 방향으로 걸어 가운데서 지나가게 했다. 24프레임, 긴 변 480px이다. 클립의 절반은 A가 앞에 있고 절반은 B가 앞에 있어서, 뒤쪽 사람이 가려진다.

- 클립마다 "왼쪽 사람"과 "오른쪽 사람"을 각각 채점한다. 정답은 첫 프레임에서 그 위치에 있던 사람이다
- 프레임마다 결과 마스크가 정답 대상과 다른 사람 중 어느 쪽과 더 겹치는지 본다. 대상이 15% 미만으로만 보이는 프레임은 채점에서 뺀다

| 세그 | 표본 | 지표 | 프레임마다 다시 고름 | 추적 | 차이 95% CI |
|------|------|------|---------------------|------|-------------|
| 정답 마스크 (추적 논리만) | 클립 40 × 2 | 맞은 프레임 비율 | 49.9% | **99.5%** | [+48.1, +50.8]%p |
| | | 지나간 뒤(후반 1/3) | 0.0% | **98.9%** | [+96.7, +100]%p |
| | | 대상 IoU | 0.498 | **0.992** | |
| 실제 YOLO26m-seg | 클립 21 × 2 | 맞은 프레임 비율 | 50.5% | **95.2%** | [+40.8, +47.9]%p |
| | | 지나간 뒤(후반 1/3) | 0.9% | **91.4%** | [+83.0, +96.4]%p |
| | | 대상 IoU | 0.464 | **0.844** | [+0.33, +0.43] |

- selector 로 다시 고른 횟수는 영상 하나에 평균 1.01~1.14회다(처음 1회 포함). 대부분 처음 고른 대상을 끝까지 놓치지 않았다
- 처리 시간은 720p, 사람 3명 기준 프레임당 약 8ms 늘어난다. 비교는 긴 변 160px로 줄인 마스크로 한다. 세그(프레임당 수백 ms)에 비하면 작다

### 개발 중 단계별 수치 (정답 마스크, "지나간 뒤")

| 단계 | 지나간 뒤 정답 |
|------|---------------|
| 예측 IoU + 색 유사도만 | 77% (클립 13개) |
| + 일부 가려짐이면 예측 위치 유지, 누적 이동량 | 89% (클립 40개) |
| + 다른 사람도 같이 추적 | 87% — 다시 나타난 대상 조각이 "새 사람"으로 등록돼 대상을 빼앗음 |
| + 놓친 대상을 예측 근처에서 다시 잡기 | **99%** |

## 한계

- 합성 영상은 사람이 옆으로 일정하게 걷는다. 방향을 갑자기 바꾸거나, 같은 옷을 입은 두 사람이 오래 겹치거나, 카메라가 크게 움직이면 더 틀릴 수 있다. 실제 영상으로는 재지 않았다
- YOLO 세그에서 지나간 뒤 약 9% 가 남아 실패했다. 원인(같은 사람 중복 검출 · 두 사람이 한 마스크로 합쳐짐)을 프레임 단위로 확인해 고쳤다 → 99.4% ([`video-tracking-hard-20261009.md`](./video-tracking-hard-20261009.md))
- "왼쪽 사람"을 **첫 프레임 기준**으로 해석한다. 영상 내내 그 순간 왼쪽에 있는 사람을 원하면 `VIDEO_TRACK_INSTANCES=false` 를 쓴다

## 테스트

`tests/unit/test_instance_tracker.py` 에 4개 테스트가 있다.

- 개수가 정해진 selector 만 추적한다
- 서로 지나간 뒤에도 같은 사람을 유지한다. 비교로, 프레임마다 다시 고르면 다른 사람으로 바뀐다
- 4프레임 동안 완전히 가려져도 다른 사람으로 옮겨 가지 않고, 다시 나타나면 이어서 따라간다
- 오래 놓치면 selector 로 다시 고른다
