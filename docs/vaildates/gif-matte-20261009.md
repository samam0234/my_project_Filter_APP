# GIF 배경 제거 경계 — 매트 (2026-10-09)

> 도구: [`scripts/experiments/gif_matte_eval.py`](../../scripts/experiments/gif_matte_eval.py) · 원자료 [`gif_matte_eval_20261009.json`](./gif_matte_eval_20261009.json)

GIF 는 픽셀마다 "투명 / 불투명" 둘뿐이다. 그래서 배경 제거의 부드러운 경계(반투명)를 알파 128 에서 잘라 왔고, 경계가 계단처럼 보였다.
**매트**는 결과를 올릴 배경색을 미리 정해 반투명 경계를 그 색과 섞어 불투명하게 남기는 방법이다 (그 색 배경 위에서는 PNG 처럼 부드럽다).

## 평가

COCO 정답 사람 마스크로 실제 배경 제거 결과(깃털 경계 RGBA)를 만들고, GIF 로 저장했다 다시 읽어 흰 배경 · 어두운 배경 위에 올린 모습을
이상적인 합성(RGBA 를 그 배경에 알파 합성)과 비교했다. 경계 띠(반투명 + 3px)만, 30장.

| 올릴 배경 | 매트 없음 (지금까지) | 밝은 배경 매트 | 어두운 배경 매트 |
|-----------|---------------------|----------------|------------------|
| 흰 배경 | 10.9 | **3.0** | 25.1 |
| 어두운 배경 | 6.7 | 24.3 | **2.6** |

(경계 띠 평균 L1, 낮을수록 이상적인 합성과 같다)

- **맞는 매트를 고르면 경계 오차가 2.6~3.6배 줄어든다**
- **반대 배경에 올리면 오히려 훨씬 나쁘다** (테두리가 보임) — 그래서 기본은 "정하지 않음"(지금까지와 같음)으로 두고, 작업실 GIF 탭에서 고르게 했다
- 배경이 정해지지 않았거나 여러 곳에 올린다면 함께 주는 **WebP**(8비트 알파)를 쓴다

API: `POST /api/v1/gif` 의 `matte` = `none`(기본) · `light` · `dark`
