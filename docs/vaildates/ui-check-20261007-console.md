## 찾은 것

| 내용 | 조치 |
|------|------|
| 확인 스크립트가 로그인 확인용 `/console/me` 의 401·403(로그인 전 · 관리자 아님)을 문제로 셌다 | `/auth/me` 401 처럼 정상으로 분류. 그 외 주소의 401·403 은 계속 문제로 잡는다 |
| 로컬에서는 사용자 앱(:5173)과 콘솔(:5174)이 **같은 세션 쿠키**를 쓴다 — 쿠키는 포트를 구분하지 않아 콘솔에 관리자로 로그인하면 같은 브라우저의 사용자 앱도 그 계정이 된다 | 기능상 문제는 아니고 배포(다른 도메인)에서는 생기지 않음. 확인 스크립트는 콘솔을 별도 브라우저 문맥으로 연다. 운영 가이드에 기록 |
| "지금 정리"는 누르지 않았다 — 이 PC 의 개발용 업로드(189시간 된 33개)가 실제로 지워진다 | 삭제 동작은 단위 테스트(`test_console_system.py`)로 확인. 화면은 미리 보기까지만 |
