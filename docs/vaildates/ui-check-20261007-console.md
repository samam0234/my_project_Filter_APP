### 원인과 수정
| 증상 | 원인 | 수정 |
|------|------|------|
| 받은 영상에 블러가 없음 | 블러 커널이 픽셀 단위(기본 15px)인데 영상은 원본 해상도 그대로 처리 — 3840폭에서 선명도 6.8→5.4 로 사실상 변화 없음 | 프레임 크기에 비례해 강도 보정 (3840폭 6.8→1.8) |
| webm 으로 나옴 | OpenCV pip 휠에 H.264 인코더 없음 | 번들 ffmpeg(`imageio-ffmpeg`)로 H.264 mp4 변환 + 오디오 유지, 실패 시 webm → avi 폴백 |
| 처리 후 다시 볼 수 없음 | 결과 Blob 이 페이지 상태에만 있어 새로고침하면 사라짐 | IndexedDB 에 마지막 1건 보관(계정별 분리), 되살리기·지우기 |
| 마음에 안 들어도 다시 하기 불편 | — | 결과가 있으면 버튼이 "다시 처리", 해석된 효과·강도 표시, "강도 60" 안내 |

- localStorage 가 아니라 **IndexedDB** 를 쓴 이유: localStorage 는 문자열만 담고 약 5MB 라 영상을 넣을 수 없다 (같은 브라우저 로컬 저장소)
- 실행 중 한 번 서버 시작이 "실패"로 보인 것은 이전 uvicorn 의 자식 프로세스가 8000 포트를 쥐고 있어서였다 — 프로세스를 정리하고 다시 띄워 재확인
