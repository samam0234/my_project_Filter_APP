## 확인하면서 찾아 고친 것

| 발견 | 고친 내용 |
|------|-----------|
| 회원이 처리하고 **좋아요**를 누르면 검수 목록에 같은 문장·같은 정답이 **2건** (회원 요청 후보 + 좋아요) | 같은 작업의 요청 후보가 있으면 새 행 대신 그 후보를 갱신 (출처를 좋아요/교정으로 승격, 교정이면 정답도). 이미 승인된 후보에 교정이 오면 다시 검수 대기 (`learning_catalog._merge_into_request`) |
| 합쳐진 후보를 삭제하면 다음 기동 때 작업 기록에서 **요청 후보가 되살아남** (중복 검사가 출처 "요청"만 봄) | 같은 작업 · 같은 문장이면 출처와 상관없이 다시 만들지 않음 |
| 콘솔 검수 대기 5,002건 중 5,000건이 의사 라벨 — 사용자 데이터가 묻힘 | 콘솔 기본 출처 필터를 **"사용자 데이터 (교정·좋아요·요청)"** 로, API `source=user` · 쉼표 목록 지원. 통계 카드도 "사용자 데이터 대기" |
| 작업 상세가 좋아요만 눌러도 **"실패 케이스 저장: 예"** 로 표시 | "피드백: 저장됨 (학습 데이터 후보)" 로 정정 |
