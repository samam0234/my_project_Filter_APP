### 3.1 배경 / 목적

### 3.2 변경 범위

- 수정된 경로: `Portfolio/ai/app.py`, 사이트 챗 API와 뇌 버튼, 안내 문구, `.gitignore`

### 3.3 기술 포인트
날짜 키는 `Asia/Seoul`이다. `GET /v1/deep`와 깊이 추론 요청이 같은 파일을 본다. 모델 호출이 실패한 뒤에는 횟수를 되돌리지 않는다. 안내 서비스에 닿기 전에 끊긴 요청은 횟수를 줄이지 않는다.
