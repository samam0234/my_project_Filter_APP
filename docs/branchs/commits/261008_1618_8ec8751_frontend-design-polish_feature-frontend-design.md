### 3.1 배경 / 목적
사용자 요청 "프론트엔드 디자인 고도화". 방향은 사용자 선택으로 "다크 유지 + 완성도", 범위는 "사용자 앱 전체"(운영 콘솔 제외).

### 3.2 변경 범위
- 추가: `frontend/src/components/home/HeroDemo.tsx`, `frontend/public/favicon.svg`, `docs/vaildates/ui-design-20261008.md`(+ 이미지 3장)
- 수정: `frontend/tailwind.config.ts`, `src/index.css`, `src/main.tsx`, `index.html`, `package.json`(pretendard), 레이아웃·공통 컴포넌트·전 페이지

### 3.3 기술 포인트
- 화면 문구를 바꾸지 않아 문구 기반 테스트 44개가 그대로 통과
- 반복되던 카드·입력칸 클래스를 스크립트로 공통 클래스에 치환해 화면 간 모양을 맞춤
- 홈 데모는 실제 사진 대신 SVG 그림 — 저작권·초상권 문제 없음. 블러 탭은 흐리지 않은 하늘·땅을 아래에 깔아 가장자리 번짐 방지
- 회원 화면 확인은 Playwright 로 API 응답을 가짜로 채워 서버 데이터를 만들지 않음

### 3.4 의도적으로 하지 않은 것
- 운영 콘솔, 밝은 테마, 사용자 테스트, 접근성 자동 점검
