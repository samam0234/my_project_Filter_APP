## 3. 상세 내용

### 3.1 배경 / 목적

안내를 더 넓게 보게 하되, 브라우저 저장소가 아니라 사이트 서버가 하루 횟수를 기억하게 하기 위함. 선택 뒤 보내기가 연속 질문에 더 맞음.

### 3.2 변경 범위

- 추가: `Portfolio/site/lib/deepQuota.ts`, `Portfolio/site/app/api/deep/route.ts`
- 수정: 챗 화면, 챗 API, Flask 안내 그래프, 안내 문구, `.gitignore`

### 3.3 기술 포인트

- 일반 답은 검색 12·채택 6·문서 5200자·문맥 6144·생성 800
- 깊이 추론은 검색 30·채택 15·문서 13000자·문맥 15360·생성 2000
- gemma4는 생각 토큰이 생성 한도를 모두 쓰면 본문이 비므로 깊이 추론도 본문으로 씀
- 횟수 표는 `deep_uses`. 실패하거나 빈 답이면 그 회는 돌려줌
- 계정 구분이 없어 10번은 이 사이트 전체 기준
- SQLite 파일과 학습 JSON은 Git에 올리지 않음

### 3.4 의도적으로 하지 않은 것

- develop/main 병합, push
- 횟수를 localStorage에 저장
- 대화 본문을 SQLite에 저장
