# Debug log — 2026-07-27

## Issue 1 — Docker Redis port already allocated

### 증상
`cut_and_keep-redis-1` 시작 실패.  
`Bind for 127.0.0.1:6379 failed: port is already allocated`

### 원인
다른 스택(`minchodan-redis`)이 호스트 6379 사용 중.

### 해결
`docker-compose.yml`에서 Redis 포트를 `6380:6379`로 변경.

### 재발 방지
- 새 프로젝트는 호스트 포트 충돌 표를 `web_management` / `repeater`에 기록
- 내부 통신은 서비스명 `redis:6379` 사용 (호스트 포트와 무관)

## Issue 2 — backend ImportError: engine

### 증상
컨테이너 재시작 루프.  
`ImportError: cannot import name 'engine' from 'app.db.session'`

### 원인
`app/db/__init__.py`가 존재하지 않는 `engine` 심볼을 export.

### 해결
`get_engine`만 export 하도록 수정 후 이미지 재빌드.

### 재발 방지
- 패키지 `__init__` re-export는 실제 심볼과 동기화 테스트

---

## Issue 3 — Backend Docker build too slow / timeout

### 증상
`pip install` 중 torch/ultralytics 다운로드로 빌드 장시간 소요.

### 원인
`requirements.txt`에 전체 ML 스택 포함.

### 해결
`requirements.docker.txt` 경량 의존성 + Dockerfile 사용.  
세그멘테이션은 stub 경로로 동작.

### 재발 방지
- 런타임 이미지와 로컬 학습 의존성 분리
